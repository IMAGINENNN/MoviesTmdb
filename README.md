# MoviesTmdb

Simple app that allows user to get data from [TMDB](https://www.themoviedb.org/). Make analysis of movies and actors.

## Installation

.NET 9.0

ASP.NET Core Web App MVC

SqlServer

Install packages:

```bash
dotnet add package Microsoft.EntityFrameworkCore
dotnet add package Microsoft.EntityFrameworkCore.SqlServer
dotnet add package Microsoft.EntityFrameworkCore.Tools
```

## Usage

On home page provided 7 functional buttons for operating. Just press them.
